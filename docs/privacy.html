APPLICATION INFORMATION

Privacy Policy

Effective October 22, 2026

Operator and scope

The project maintainer operates Battle Logic Lab Publisher, a personal-use video creation and publishing application. Use project support to request a private follow-up for privacy or deletion matters. Do not post personal information, channel identifiers or credentials in a public issue. This policy covers this information website and the application’s use of Google and YouTube data.

Google and YouTube data accessed

The authorized workflow accesses the operator’s YouTube channel identity, video IDs, titles, descriptions, tags, audience settings, privacy status, scheduled publication time and processing results. OAuth access and refresh tokens authorize these operations. For topic research, the app retrieves public video metadata, including channel identifiers, publication dates and visible view, like and comment counts. It does not retrieve comment text as part of that research.

The application does not request Google passwords, Gmail messages or Google Drive files. This website has no login form or credential collection.

How data is used

Data is used to confirm the correct destination channel, select relevant recent topics, prepare accurate video metadata, upload and schedule videos, verify publication and prevent duplicates. Research is based on a limited sample of public metadata; it does not guarantee trends, reach or revenue.

Google user data is not sold, used for advertising profiles or provided for training generalized AI models. This implementation uses local battle simulation, templated narration and local speech synthesis.

Storage and service providers

OAuth credentials are configured as GitHub Actions repository secrets or restricted production-host environment secrets. Publishing state and reference IDs are recorded in a repository ledger; that repository is public, so non-secret operational records can be publicly visible. Credentials must never be stored in that ledger or site source.

Workflow artifacts may include generated videos, research evidence, public metadata and non-secret connection results; they are configured for two-day retention on GitHub Actions. Downloads or operator-held copies can persist separately. The ledger remains until the operator removes it. Google and YouTube process authorization and publishing requests; GitHub hosts source, automation records, artifacts and this website. A separately connected production host processes rendering and publishing when enabled.

GitHub Pages may record visitor technical information, including IP addresses, for security and service operation under GitHub’s Privacy Statement. This site includes no operator-added analytics, advertisements or tracking cookies.

Revoke access and request removal

The operator can revoke the application’s Google access at Google Account permissions. Revocation stops future authorized API access; it does not itself delete previously published YouTube videos or existing records. Videos can be managed in YouTube Studio.

To request removal of application-held data, use the support link above to request a private follow-up. Share any necessary record identifiers only through the private channel arranged by the maintainer. Do not publish personal data or send tokens or passwords. The operator will remove applicable records from active storage and address accessible artifacts and repository history where needed. Public repository forks, third-party caches and service-provider backups may retain copies outside the operator’s direct control; the operator cannot promise their immediate erasure.

Google API user data

Battle Logic Lab Publisher’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements. YouTube data and services are also subject to Google’s Privacy Policy and the YouTube Terms of Service.

Policy changes

Material changes will be described on this page with an updated effective date. This application is intended for the operator’s personal channel, not for collecting data from children or offering accounts to the public.
