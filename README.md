Free CPU narration, API-fetched mini/chibi characters, original animated layouts and game-mechanics simulations, reusing the existing YouTube channel connection.

The first connection attempt found an expired/revoked Google token; no new video has been uploaded.

The previous movie workflows are preserved under `docs/legacy-workflows/` and cannot run. Existing videos and history are untouched.
